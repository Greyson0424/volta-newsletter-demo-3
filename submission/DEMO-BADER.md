# Bader demo script - maximum 3 minutes

Audience: the person who will use the newsletter. Assume setup is already complete. Use everyday language. Do not discuss code, configuration, or repository files.

## 0:00–0:20 - The outcome

Show Claude Code or Cursor with the VOLTA project open.

Say:

“This creates VOLTA’s monthly member newsletter. It finds upcoming events and community stories, avoids repeating previous wins, and gives you a visual editor before anything is sent.”

## 0:20–0:45 - Start a newsletter

Type:

`newsletter`

Say:

“That is the only instruction needed. It uses the current month automatically, gathers source material, and prepares a draft. It never sends anything.”

## 0:45–1:10 - Open Newsletter Studio

Open the Newsletter Studio link.

Say:

“This is where you work on the newsletter. You do not need to edit through chat. The subject, preview text, opening, stories, events, and final call to action are all here.”

## 1:10–1:50 - Make a visible edit

Demonstrate:

1. Change the opening note.
2. Edit an event title or description.
3. Add an event with a date, start time, end time, location, and link.
4. Remove an unwanted item.

Say:

“Events are flexible, while community wins are capped at two so the email stays focused. Removed items are kept in the background so the source history is not lost.”

## 1:50–2:20 - Engagement features

Show the Google Calendar and Outlook Calendar buttons and the Community Call to Action.

Say:

“Subscribers can add events directly to their calendar. The final action can ask members to register, apply, complete a survey, or simply reply with a win for next month.”

## 2:20–2:45 - Export

Select **Save draft**, then **Export for Mailchimp**.

Say:

“The export prepares the finished email, a plain-text version, calendar attachments, and organized copy for Mailchimp. You still review the audience and send the final email from Mailchimp.”

## 2:45–3:00 - Close

Show the finished newsletter preview.

Say:

“The result is a sourced, editable VOLTA newsletter that is ready for final review and delivery without rebuilding the email every month.”
